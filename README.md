# diy_drone
基于STM32F103C8T6的DIY无人机

# 文件说明
此工程是跟着尚硅谷无人机教程制作的
原视频地址：https://www.bilibili.com/video/BV1cRso6FEuM

过程中遇到挺多问题，但好在最后完成了基本制作，能够实现基本的飞行控制，以及定高，悬停等功能。

此工程中包含了以下文件：
- diy_drone文件夹为飞控板的源码；
- diy_drone_ctrl文件夹为遥控板源码；
- PCB文件夹为嘉立创的eda设计文稿，建议用最新日期的版本；


PCB设计文件建议使用最新日期的
